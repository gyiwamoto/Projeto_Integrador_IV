TÍTULO: Análise de Risco para Concessão de Crédito com Técnicas de Ciência de Dados<br>
<br>
RESUMO<br>
Este relatório parcial apresenta os resultados iniciais do Projeto Integrador IV, desenvolvido por um grupo misto de alunos dos cursos de Ciência de Dados e Engenharia da Computação da UNIVESP. O objetivo é aplicar técnicas de ciência de dados e aprendizado de máquina a bases públicas do Banco Central, com foco na análise de risco para concessão de crédito. Até o momento, foram realizadas reuniões de alinhamento, levantamento bibliográfico, seleção preliminar de bases de dados e contato inicial com a comunidade externa. Os resultados parciais incluem a definição do problema, a delimitação do escopo e a execução de análises exploratórias iniciais.<br>
Palavras-chave: risco de crédito; ciência de dados; aprendizado de máquina; análise exploratória; Banco Central.
